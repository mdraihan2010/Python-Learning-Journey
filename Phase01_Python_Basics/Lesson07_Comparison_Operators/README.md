# 🐍 Lesson 07 - Comparison Operators

## 📖 Overview

This lesson introduces **Comparison Operators** in Python. Comparison operators are used to compare two values and return a Boolean result (`True` or `False`). They are essential for making decisions in programs and are commonly used with conditional statements and loops.

## 📚 Topics Covered

- Equal to (`==`)
- Not Equal to (`!=`)
- Greater Than (`>`)
- Less Than (`<`)
- Greater Than or Equal to (`>=`)
- Less Than or Equal to (`<=`)
- Comparing Numbers
- Comparing Strings
- Boolean Results (`True` and `False`)
- Using the `type()` Function with Boolean Values
