# 🐍 Lesson 06 - Type Casting

## 📖 Overview

This lesson introduces **Type Casting** in Python. Type casting is the process of converting a value from one data type to another. I practiced converting between integers, floating-point numbers, strings, and boolean values using Python's built-in type conversion functions.

## 📚 Topics Covered

- What is Type Casting?
- Implicit Type Casting
- Explicit Type Casting
- `int()` Function
- `float()` Function
- `str()` Function
- `bool()` Function
- Type Conversion Examples
- Checking Data Types with `type()`
