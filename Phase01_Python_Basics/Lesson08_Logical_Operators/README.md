# 🐍 Lesson 08 - Logical Operators

## 📖 Overview

This lesson introduces **Logical Operators** in Python. Logical operators are used to combine multiple conditions and evaluate Boolean expressions. They are essential for writing decision-making statements and controlling program flow.

## 📚 Topics Covered

- Logical AND (`and`)
- Logical OR (`or`)
- Logical NOT (`not`)
- Combining Multiple Conditions
- Boolean Expressions
- Truth Values (`True` and `False`)
- Using Logical Operators with Comparison Operators
- Practical Examples of Logical Operators

## 🎯 What I Learned

- What logical operators are and why they are used.
- How the `and` operator returns `True` only when all conditions are `True`.
- How the `or` operator returns `True` when at least one condition is `True`.
- How the `not` operator reverses a Boolean value.
- How to combine comparison operators with logical operators.
- How logical operators help in making complex decisions in Python programs.
