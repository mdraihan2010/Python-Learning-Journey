# 🐍 Lesson 05 - Arithmetic Operators

## 📖 Overview

This lesson introduces **Arithmetic Operators** in Python. I practiced performing basic mathematical operations using different arithmetic operators and learned how Python evaluates arithmetic expressions.

## 📚 Topics Covered

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Floor Division (`//`)
- Modulus (`%`)
- Exponentiation (`**`)
- Arithmetic Expressions
- Operator Precedence (PEMDAS/BODMAS)

## 🎯 What I Learned

- How to perform basic mathematical operations in Python.
- The difference between `/` (Division) and `//` (Floor Division).
- How to calculate the remainder using the `%` (Modulus) operator.
- How to calculate powers using the `**` (Exponentiation) operator.
- How Python evaluates arithmetic expressions.
- How operator precedence determines the order of calculations.
