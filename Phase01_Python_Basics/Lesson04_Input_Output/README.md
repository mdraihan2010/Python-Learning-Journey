# 🐍 Lesson 04 - Input & Output

## 📖 Overview

This lesson focuses on taking input from the user and displaying output in Python. It introduces the `input()` function, different ways of printing output, and basic user interaction through simple practice programs.

## 📚 Topics Covered

- User Input using the `input()` function
- Output using the `print()` function
- Taking single input
- Taking multiple inputs
- Displaying user information
- Basic Input & Output practice
