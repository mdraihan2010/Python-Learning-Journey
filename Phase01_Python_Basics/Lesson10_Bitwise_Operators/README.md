# 🐍 Lesson 10 - Bitwise Operators

## 📖 Overview

This lesson introduces **Bitwise Operators** in Python. Bitwise operators work directly with the binary representation of integers. They are commonly used in low-level programming, optimization, embedded systems, and competitive programming.

## 📚 Topics Covered

- Binary Number Representation
- Bitwise AND (`&`)
- Bitwise OR (`|`)
- Bitwise XOR (`^`)
- Bitwise NOT (`~`)
- Left Shift (`<<`)
- Right Shift (`>>`)
- Practical Examples of Bitwise Operations
