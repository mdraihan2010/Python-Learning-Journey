# 🐍 Lesson 04 - Match Case

## 📖 Overview

This lesson focuses on the **`match-case` statement** in Python, which is used to perform pattern matching and handle multiple possible conditions in a clean and structured way.

Through practical examples, I learned how `match-case` can be used as an alternative to multiple `if-elif-else` statements in certain situations.

---

## 📚 Topics Covered

- Introduction to `match-case`
- Basic `match` statement
- Using multiple `case` statements
- Default case using `_`
- Matching different values
- Using `match-case` for menu-based programs
- Comparing `match-case` with `if-elif-else`
