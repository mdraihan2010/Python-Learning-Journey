# 🐍 Lesson 18 - Exception Handling

## 📖 Overview

In this lesson, I practiced **Exception Handling** in Python.

Exception handling allows programs to handle errors without stopping unexpectedly. I learned how to use `try`, `except`, `else`, and `finally` to manage errors and make Python programs more reliable.

---

## 📚 Topics Covered

- Introduction to exception handling
- Understanding errors and exceptions
- Using the `try` block
- Using the `except` block
- Handling `ZeroDivisionError`
- Handling `ValueError`
- Handling `TypeError`
- Handling `IndexError`
- Handling `KeyError`
- Using multiple `except` blocks
- Using `else` with exception handling
- Using `finally` for cleanup
- Raising exceptions using `raise`
- Handling user input errors
- Practical exception handling examples
