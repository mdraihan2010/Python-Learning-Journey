# 🐍 Lesson 12 - Tuples

## 📖 Overview

In this lesson, I practiced **Tuples** in Python.

Tuples are used to store multiple values in a single variable, similar to lists. However, unlike lists, tuples are **immutable**, meaning their elements cannot be changed after the tuple is created. I practiced creating tuples, accessing elements, using indexing and slicing, and performing different tuple operations.

---

## 📚 Topics Covered

- Introduction to tuples
- Creating tuples
- Tuple syntax and structure
- Accessing tuple elements using indexing
- Positive and negative indexing
- Tuple slicing
- Tuple immutability
- Using the `len()` function with tuples
- Checking elements using the `in` keyword
- Counting elements using `count()`
- Finding element positions using `index()`
- Iterating through tuples
- Basic tuple operations
