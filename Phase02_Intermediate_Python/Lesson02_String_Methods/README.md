# 🐍 Lesson 02 - String Methods

## 📖 Overview

This lesson focuses on **Python String Methods**, which are built-in functions used to manipulate and process string data efficiently.

Through practical examples, I explored various string methods to modify, search, format, and analyze strings in Python.

- `upper()`
- `lower()`
- `title()`
- `capitalize()`
- `swapcase()`
- `strip()`
- `replace()`
- `find()`
- `count()`
- `startswith()`

- `split()`
