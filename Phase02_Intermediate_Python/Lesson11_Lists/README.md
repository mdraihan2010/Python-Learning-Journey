# 🐍 Lesson 11 - Lists

## 📖 Overview

In this lesson, I practiced **Lists** in Python.

Lists are used to store multiple values in a single variable. I learned how to create lists, access and modify elements, add and remove items, and perform different operations using Python lists.

---

## 📚 Topics Covered

- Introduction to lists
- Creating lists
- Accessing list elements using indexing
- Positive and negative indexing
- Modifying list elements
- Adding elements using `append()`
- Adding elements using `insert()`
- Removing elements using `remove()`
- Removing elements using `pop()`
- Using `len()` with lists
- Checking elements using the `in` keyword
- Iterating through lists
- Performing basic list operations
