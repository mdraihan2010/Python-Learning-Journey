# 🐍 Lesson 06 - While Loop

## 📖 Overview

In this lesson, I practiced the **While Loop** in Python.

The `while` loop is used to repeatedly execute a block of code as long as a specified condition remains `True`. I practiced different ways of using `while` loops to perform repetitive tasks and control program execution based on conditions.

---

## 📚 Topics Covered

- Introduction to `while` loops
- Basic `while` loop syntax
- Using conditions with `while`
- Incrementing and updating variables
- Printing sequences using `while`
- Creating countdown programs
- Repeating tasks until a condition becomes `False`
- Using `break` and `continue`
- Avoiding infinite loops
- Solving basic `while` loop problems
