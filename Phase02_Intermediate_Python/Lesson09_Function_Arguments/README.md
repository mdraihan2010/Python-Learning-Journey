# 🐍 Lesson 09 - Function Arguments

## 📖 Overview

In this lesson, I practiced **Function Arguments** in Python.

Function arguments allow us to pass values to a function when calling it. I practiced different ways of passing arguments to functions, including positional arguments, keyword arguments, default arguments, and variable-length arguments.

---

## 📚 Topics Covered

- Introduction to function arguments
- Positional arguments
- Keyword arguments
- Default arguments
- Variable-length arguments
- Using `*args`
- Passing multiple values to a function
- Using arguments with function parameters
- Writing flexible and reusable functions
- Solving basic problems using function arguments
