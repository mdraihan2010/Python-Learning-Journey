# 🐍 Lesson 05 - For Loop

## 📖 Overview

In this lesson, I practiced the **For Loop** in Python.

The `for` loop is used to repeat a block of code while iterating through a sequence or a range of values. I practiced different ways of using `for` loops with the `range()` function and other basic looping concepts.

---

## 📚 Topics Covered

- Introduction to `for` loops
- Using the `range()` function
- Looping through a sequence
- Printing values using loops
- Using different start and stop values
- Using step values in `range()`
- Nested loop concepts
- Performing calculations using loops
- Solving basic loop-based problems
