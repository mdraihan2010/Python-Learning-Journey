# 🐍 Lesson 03 - Conditional Statements

## 📖 Overview

This lesson focuses on **Conditional Statements** in Python, which allow a program to make decisions based on different conditions.

Through practical examples, I learned how to use conditional statements to control the flow of a program and execute different blocks of code depending on whether a condition is `True` or `False`.

---

## 📚 Topics Covered

- `if` statement
- `if-else` statement
- `if-elif-else` statement
- Nested `if` statements
- Multiple conditions
- Using comparison operators in conditions
- Using logical operators in conditions
