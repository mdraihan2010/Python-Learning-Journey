# 🐍 Lesson 10 - Recursion

## 📖 Overview

In this lesson, I practiced **Recursion** in Python.

Recursion is a programming technique where a function calls itself to solve a problem. I learned how recursive functions work, the importance of a base case, and how a problem can be solved by breaking it down into smaller similar subproblems.

## 📚 Topics Covered

- Introduction to recursion
- Understanding recursive functions
- Function calling itself
- Base case
- Recursive case
- Preventing infinite recursion
- Calculating factorial using recursion
- Solving simple mathematical problems using recursion
- Comparing recursion with iteration
- Solving basic recursion-based problems
