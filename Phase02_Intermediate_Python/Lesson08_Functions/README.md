# 🐍 Lesson 08 - Functions

## 📖 Overview

In this lesson, I practiced **Functions** in Python.

Functions are reusable blocks of code designed to perform specific tasks. I learned how to create and call functions, pass arguments, use parameters, and return values. Functions help make programs more organized, reusable, and easier to maintain.

---

## 📚 Topics Covered

- Introduction to functions
- Creating functions using the `def` keyword
- Calling functions
- Function parameters and arguments
- Functions with multiple parameters
- Using the `return` statement
- Functions with and without return values
- Reusing functions
- Organizing code using functions
- Solving basic problems using functions
