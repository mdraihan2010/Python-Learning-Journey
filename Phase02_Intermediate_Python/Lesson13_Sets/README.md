# 🐍 Lesson 13 - Sets

## 📖 Overview

In this lesson, I practiced **Sets** in Python.

A set is a collection used to store multiple unique values. Unlike lists and tuples, sets do not allow duplicate elements and are unordered. I practiced creating sets, adding and removing elements, performing set operations, and working with different set methods.

---

## 📚 Topics Covered

- Introduction to sets
- Creating sets
- Unique elements in sets
- Unordered nature of sets
- Adding elements using `add()`
- Adding multiple elements using `update()`
- Removing elements using `remove()`
- Removing elements using `discard()`
- Removing random elements using `pop()`
- Clearing a set using `clear()`
- Checking elements using the `in` keyword
- Union of sets
- Intersection of sets
- Difference between sets
- Basic set operations
