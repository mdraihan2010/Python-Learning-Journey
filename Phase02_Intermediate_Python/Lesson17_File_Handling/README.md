# 🐍 Lesson 17 - File Handling

## 📖 Overview

In this lesson, I practiced **File Handling** in Python.

File handling allows programs to create, read, write, and modify files. I learned how to work with files using Python's built-in functions and methods, and practiced managing file data through different examples.

---

## 📚 Topics Covered

- Introduction to file handling
- Opening files using `open()`
- Reading files using `read()`
- Reading files using `readline()`
- Reading files using `readlines()`
- Writing data using `write()`
- Writing multiple lines using `writelines()`
- Appending data using `a` mode
- Understanding file modes
- Using `with open()` for file handling
- Closing files using `close()`
- Creating and writing to files
- Reading and displaying file contents
- Working with text files
