# 🐍 Lesson 14 - Dictionaries

## 📖 Overview

In this lesson, I practiced **Dictionaries** in Python.

Dictionaries are used to store data in **key-value pairs**. I learned how to create dictionaries, access and modify values, add and remove items, and use different dictionary methods to work with structured data.

- Key-value pairs
- Accessing dictionary values
- Adding new key-value pairs
- Updating dictionary values
- Removing dictionary items
- Using `keys()`
- Using `values()`
- Using `items()`
- Using `get()`
- Using `update()`
- Using `pop()`
- Using `popitem()`
- Using `clear()`
- Checking keys using the `in` keyword
- Iterating through dictionaries
